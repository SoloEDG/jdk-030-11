# 栈闩工房

机关推箱子纯前端工房。不同种类的箱子触发对应踏板，踏板改变门与地板，记录步数并保存已完成关卡的最佳成绩。

关卡「货梯试车」带有凸轮盘工单：用给定的圆弧片与直边片拼出闭合轮廓，选定滚轮直径与内圆角，校核各停靠转角在门开窗口内的平层余量后实装；游戏里 Q/E 摇手轮换层，人和箱随厢走，只有真正平齐时才能跨出。

## 本地运行

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run typecheck
npm run build
```

货梯凸轮校核（规范排法、自动搜索最优排法、大滚轮搭桥超差、完整通关演练）：

```bash
npm run check:lift
```

## Docker

```bash
docker compose up --build
```

浏览器打开 http://127.0.0.1:8030
